## 0. 风格微调声明（相对 academic 预设）

| 项 | 预设常量 | 本项目取值 | 理由 |
| :-- | :-- | :-- | :-- |
| 顶条文字 | — | 章节名（22px 白）+ 右上「HeteroNexus · 2026 Q1」（14px `#BFD3EE`） | 全篇章节定位一致 |
| 页脚左 | 单位 logo | 文字「中国人民大学 · 大学生创业训练计划」14px `#8B97A8` | 无校徽素材，用文字替代，不伪造 LOGO |

其余色板、字体、字号阶梯、卡体规则、硬闸门**全部沿用 academic 预设**。

## 1. 画布与母版

- 画布：`1280 × 720`，安全边距左右 `40`
- 顶条模式：**A3**（深蓝顶条 + 内容页默认）

| 区域 | 范围 | 高度 | 规则 |
| :-- | :-- | :-- | :-- |
| A 顶条 | y 0–72 | 72 | 底色 `#1E4FA8`；左章节名 22px Bold 白；右标识 14px `#BFD3EE` |
| B 内容区 | y 72–660 | 588 | `padding: 20px 40px 12px 40px`；实际可用 `1200 × 556` |
| D 页脚 | y 660–720 | 60 | 左文字灰 14px；右页码 `NN / 16` 14px `#1E4FA8` Bold |

封面 / 章节扉页 / 结束页采用自定义版式，允许省略 A/D。
**高度校验**：72 + 588 + 60 = 720 ✅

## 2. 色彩系统

| 角色 | hex | 用途 | 面积占比 |
| :-- | :-- | :-- | :-- |
| 主蓝 | `#1E4FA8` | 顶条、编号方块、强调 | ≤ 45% |
| 藏蓝 | `#0E3F8C` | 深底块、章节扉页、重点卡 | ≤ 20% |
| 浅蓝 | `#E8EFF8` / `#F0F5FC` | 卡片底、表头 | ≤ 35% |
| 中蓝 | `#3D7BD9` | 描边、图表第二色 | ≤ 15% |
| 警示红 | `#D9534F` | 风险、退化数据 | ≤ 3% |
| 数据黄 | `#FFC107` | 关键结论高亮、对比序列 | ≤ 3% |
| 中性 | `#1A2230` / `#4A5568` / `#8B97A8` / `#D6DCE5` | 文本、线框 | 剩余 |
| 背景 | `#FFFFFF` / `#F7F9FC` | 页面与卡体 | 30–55% |

**渐变方案**：仅用于封面顶条与章节扉页底纹 —— `linear-gradient(135deg, #0E3F8C 0%, #1E4FA8 100%)`。
**半透明策略**：封面 / 扉页背景拓扑 SVG 使用 `opacity: 0.12`；卡体不使用渐变填充。
**禁色**：金色、紫粉玫红、橙绿大色块、纯黑大底 —— 全篇禁用。

## 3. 字体系统

字体家族 **2 套**：

| 用途 | 字体 | 回退 |
| :-- | :-- | :-- |
| 中文标题 / 正文 / 数据 | 思源黑体 | `"Source Han Sans SC", "Noto Sans SC", "Microsoft YaHei", sans-serif` |
| 封面英文长标题 / 引文 | 思源宋体 | `"Source Han Serif SC", Georgia, serif` |

| 层级 | px | 字重 | 行高 | 用途 |
| :-- | :-- | :-- | :-- | :-- |
| 封面中文主标 | 64 | Bold | 1.2 | 仅封面 |
| 封面英文长标题 | 30 | Bold Serif | 1.3 | 仅封面 |
| 章节大数字 | 160 | Bold | 1.0 | 章节扉页 |
| KPI 巨数字 | 96 | Bold | 1.0 | 数据锚点 |
| 页面主标（顶条） | 22 | Bold | 1.3 | 全篇锁定 |
| 卡片内小标 | 26 | Bold | 1.4 | 卡片头 |
| 正文 | 22 | Regular | 1.55 | 段落 |
| 表格 | 20 | Regular / Bold | 1.4 | 表头表体 |
| 注解 / 页脚 | 14 | Regular | 1.4 | 单位、来源、页码 |

**巨型数字必须与正文不同字重**：正文 22 Regular，KPI 96 Bold。
**禁止**：楷体、行书、毛笔、艺术字、3D 字、空心字。

## 4. 信息密度基线

- 内容页 C 区累计高 ≥ 476px（本项目实际 556px）✅
- 常规卡填充率 ≥ 80%；高 ≥ 380px 的卡正文 ≥ 130 字
- 卡内 padding：上下 16、左右 ≥ 20；卡尾元素 `marginTop: 'auto'` 锚底
- 兄弟卡高度差 ≤ 8px
- 常规内容页留白 ≤ 35%；仪式段（封面 / 扉页 / 结束）≤ 35%
- 每个内容页 ≥ 3 类组件、≥ 4 种修辞、≥ 3 个层次
